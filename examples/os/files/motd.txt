welcome to mettle os.

this text is a real file on a real filesystem. the build script packed it into
an archive at sector 1024, and the first time the kernel found the partition
blank it laid a filesystem down and wrote the archive into it. everything you
write from here on survives a reboot.

try help for the command list, df for the filesystem, disk for the drive.
try mkdir, write, cat, cp, mv, rm. the files window browses the same tree.
