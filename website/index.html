This is your language. Do what you want with it.

Systm's Potentia runs LLMs on Mettle, faster than llama.cpp on the same card.

Its GPU kernels are Mettle, compiled straight to PTX with no nvcc, C++ or Python in the pipeline. The build fails unless the GPU matches an independent CPU reference, logit for logit.

Gemma 4 12B and 26B-A4B, QAT Q4_0, on one RTX 5060 Ti, against llama.cpp from LM Studio with every layer on the GPU and one engine in VRAM at a time. Energy is board joules per token. At 16 requests, throughput is 473 against 446 tokens a second.

Everything else stays close to C.

Every whole program in the benchmark suite, including parsers, compressors, interpreters and solvers.

clang 22.1.6 on Windows, on an i7-12700K, best of 15 pinned runs. Under -march=native, clang's physics_grid returns a different checksum. Run them with tools/benchmark/mc.ps1 -Suite 3.

A kernel is a Mettle function. It compiles straight to PTX or Metal, and one line launches it.

kernel(block = 256) vadd(a: float32*, b: float32*,
                         c: float32*, n: int32) {
  var i: int32 = block.x * block_dim.x + thread.x;
  if (i < n) {
    c[i] = a[i] + b[i];
  }
}

dispatch vadd[work: n](da, db, dc, n);
