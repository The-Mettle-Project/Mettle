This is your language.

Struct layouts, optimizer passes and the register allocator are Mettle functions in your own program.

The compiler runs them, checks what they return, and proves the claims you write beside your code. Sixteen whole programs average {{C_O3}}× the run time of clang -O3. The parser, optimizer, assembler, linkers and runtime are one codebase with no LLVM.

Program the compiler

Each one runs while the program builds, and the compiler checks what it hands back: a pass against the function it replaced, an allocator against which values are live together, a generator against the rule it ships with. mettle expand prints the result as plain Mettle.

Decide where fields live

@soa gives each field its own column, and the loop stays as written. @hot_cold, @compact, @tagged and @allocate_with are library code too, and @layout writes your own.

One million records, best of 40 passes, against the same fields in a plain struct.

Add an optimizer pass

A @pass takes one function's IR and returns new IR at the point it names. The compiler runs the old and new function on generated inputs. This pass shifts one bit too far, and the build stops.

Write build rules

A @rule reads the checked program, the machine code it became, or a recorded run. It can stop the build or propose a fix that --fix applies. A module's exported rules bind every program that imports it.

Language

Structs, tagged enums, generics, closures and slices, with manual memory and no garbage collector. if, match, switch and blocks give values, and a local leaves its type off when the line already says it.

Test and trace without building

mettle test runs @test functions in the compiler's interpreter, with no codegen and no link. mettle trace prints the source with the values each line took.

Tagged enums

Generics
One copy per set of type arguments. Generic structs take methods, and Box<Fn(int64) -> int64> is a type argument like any other.
Closures
Fn(int32) -> int32 captures by value, and fn(int32) -> int32 is a bare pointer.
Slices and shaped views
T[] carries its length and T[,] its extents. In T[32, 32] the shape is in the type and every index is proven.
defer and errdefer
defer runs on every path out of a scope, errdefer only when the function returns an error.
Interpolated strings
Any expression fits in the braces: "twice={n * 2}".
Standard library
1282 functions, from system calls up through sockets, TLS streams, HTTP/2, processes, threads and collections.
std/math
Every function within one ulp of the true result. sin, cos and tan reduce any argument exactly.

Change it while it runs

mettle live app.mettle builds and starts the program, and each save becomes a patch that lands at the next quiesce. Function bodies, signatures and struct layouts all change. Every frame on the stack moves to the new code with its locals, and heap objects convert in place, even to and from columns.

A crash waits for its fix

A fault pauses the program until a save fixes it. Then it continues from its last quiesce. In this recording the fix landed in {{LIVE_FIX_MS}} ms.

One toolchain

Frontend, optimizer, interpreter, code generators, assembler, linkers and runtime in one codebase, with no LLVM and no outside assembler. Windows and Linux builds link with its own PE and ELF linkers, against its own runtime.

Ask what it decided

--explain reports every optimization decision, the reason for each refusal and what the build took on trust. mettle why prints the chain behind an effect or a proven type.

Potentia

An LLM inference engine from Systm, the company that develops Mettle. Its GPU kernels are Mettle, compiled straight to PTX.

Against llama.cpp on one RTX 5060 Ti: 1.7 to 2.4× faster to the first token, 1.07 to 1.41× faster generating a reply, 8.5 to 23.5× less RAM on the 26B model, and 19 to 38% less energy per token.

Gemma 4 12B and 26B-A4B, QAT Q4_0, against llama.cpp from LM Studio with every layer on the GPU and one engine in VRAM at a time. Energy is board joules per token. At 16 requests, throughput is 473 against 446 tokens a second.

Mettle OS

A bootable 64-bit operating system with a scheduler, a filesystem, disk and GPU drivers, and a windowed desktop with a shell. Nothing outside the Mettle compiler builds it.
