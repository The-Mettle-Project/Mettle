N0001A described machine is not one the compiler can read

Reported by the compiler as an error or warning.

mettle explain N0001

A machine is a const of std/machine's MachineInsn, one row per instruction, and every field of a row is a literal, because all of it is answered before anything runs.

Example

const ISA: MachineInsn[1] = [
  { name: "addi", encoding: "10 %0 %1", operands: 2,
    reads: "%1", writes: "%0", semantics: "ins_addi" },
];

An encoding is pairs of hex digits and operand slots, it starts with at least one fixed byte, and no two instructions share their fixed prefix, because that prefix is what a decoder matches on. reads and writes may only name operands the encoding actually carries. A semantics function takes the three operand slots and returns the next instruction index or -1.
