T0002A reference twin could not be checked

Reported by the compiler as an error or warning.

mettle explain T0002

The pair was declared and the prober could not generate inputs it could run: a parameter shape it has no values for, or a construct the interpreter cannot execute. The build goes on and this warning stands, because a check that did not run must not read as one that passed.

--report-twins prints what each pair was checked on, so a pair that was checked on nothing is visible beside the pairs that were.

Fix: narrow the parameters to shapes the prober can build, or accept that this pair is unchecked and know that it is.
