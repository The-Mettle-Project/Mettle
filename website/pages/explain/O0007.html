O0007Calling a destructor by name

Reported by the compiler as an error or warning.

mettle explain O0007

T_drop__ptr runs only the type's own cleanup. Calling it leaves the fields undropped and leaves the compiler thinking the value is still alive, so it would be dropped again at the end of its scope.

Fix: write drop(value). It runs the destructor, drops the fields, and marks the value gone.
