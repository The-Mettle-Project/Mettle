D0002A function's longest path cannot be bounded

Reported by the compiler as an error or warning.

mettle explain D0002

A deadline that cannot be proven is not a deadline. The path runs through something with no bound the compiler can find: a loop whose trip count depends on a value it cannot see, a call through a pointer, a call to a function with no body here, or an asm block.

Example

fn tick() where cycles < 4000 {
  while (i < limit) { ... }   // D0002: `limit` is a global
}

Fixes

  • bound the loop with a constant, or with a declared type that carries one, so the trip count is a fact rather than a guess

  • build with --pgo, which interprets the program and lets a measured trip count stand in; the deadline then holds on evidence, and --report-deadlines says so in those words

  • take the unbounded work out of the function that carries the deadline
