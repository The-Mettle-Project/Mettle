chosen-indexThe condition reads at an index the loop chose

Reported by --explain after a verdict.

mettle explain chosen-index

if (a[i] > a[best]) { best = i; } finds the index of the largest element, but it reads a[best] in the comparison, and best is set inside the if. Every iteration's load waits on the previous iteration's choice, so the iterations form a chain.

Fix: keep the best value in a variable of its own beside its index:

var best_value = a[0];
for i in 0..n {
    if (a[i] > best_value) { best_value = a[i]; best = i; }
}
