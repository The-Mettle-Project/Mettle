P0004The declared-type prover stopped at its step ceiling

Reported by the compiler as an error or warning.

mettle explain P0004

The prover that settles declared types stops after a fixed number of steps so one hard predicate cannot stall a build. Past that point it answers every remaining question as unknown, and an unknown proof refuses exactly as a false one does.

--report-proofs prints what each proof cost.

Fix: narrow the values a declared type is computed from so the prover settles sooner, or split the function that carries the proofs.
