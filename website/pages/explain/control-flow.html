control-flowThe loop body branches on data

Reported by --explain after a verdict.

mettle explain control-flow

The body has a data-dependent if. The lane vectorizer runs an if/else as masks: both arms compute in every lane and a select keeps the right one. It takes that shape only inside a loop it can run at all, and the remark says where it stopped:

  • the loop test is not a signed counter < bound

  • the counter does not step by one as the last statement

  • an element is not 32 bits wide

  • an address is not base[i] with the counter as the index

The fix line under the remark is the fix for that stop.
