local-memoryA kernel's local was emitted as memory

Reported by --explain after a verdict.

mettle explain local-memory

A scalar local of a kernel lives in a register. An array or a record lives in registers too when every use names one element with a constant index, because each element can then take a register of its own. A use that indexes with a run-time value, passes the address to a helper or stores the address keeps the whole value in the work item's own memory, and every access to it becomes a load or a store.

On PTX that memory is .local. Where ptxas is on PATH the report reads its stack frame for the kernel: a frame at least as large as the value confirms it, and a frame of zero means the assembler kept the value in registers, so the report counts it as a register value and lists nothing for it.

On Metal the value stays one array or record in the emitted source, and Apple's compiler decides where it lives.

Fix: index it with constants, which comptime for gives a loop with a constant count, or keep the running values in scalar locals.
