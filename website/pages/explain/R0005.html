R0005A rule answered differently on a second run

Reported by the compiler as an error or warning.

mettle explain R0005

Under mettle test every @rule is run again over a freshly placed copy of the same program image, and this rule did not give the same verdict twice. A rule is code the compiler runs and does not trust, so a verdict that moves is reported rather than picked from.

A rule that is a function of the program it reads answers the same way every time. One that does not is reading something else: an uninitialised local, an address, or an order the compiler is free to change.

Fix: make the rule depend only on the Program it was handed.
