M0123A signed operation left its type

Reported by the compiler as an error or warning.

mettle explain M0123

Signed +, - and * in Mettle wrap rather than trapping, the way the machine does. --check-overflow says to stop instead, and this is what it stops on: the result of the operation is not a value the type can hold.

Example

var big: int32 = 2000000000;
var sum: int32 = big + big;    // M0123 under --check-overflow

The check is not emitted where a declared type already bounds the operands tightly enough that the result has to fit:

type Half = int32 where value >= 0 && value <= 1000000000;
fn blend(a: Half, b: Half) -> int32 { return a + b; }

Two Halves sum to at most two billion, which an int32 holds, so nothing is emitted and --explain reports the deletion under **proven by type**. A program whose every signed operation is proven that way compiles to the same bytes with the flag as without it.

Unsigned arithmetic is not checked. Wrapping is what unsigned types are reached for in a hash or a checksum, and a check there would refuse the programs that want it.
