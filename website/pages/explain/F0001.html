F0001A function reaches an effect it forbids

Reported by the compiler as an error or warning.

mettle explain F0001

A function declared forbids E performs E itself or reaches a function that does. The message gives the call chain from the forbidding function to the source, and the notes mark every call on the way and the line that performs the effect.

What a function performs is inferred, never annotated in the middle: a function performs what it is declared with, and everything its callees perform. alloc, asm and syscall are built in, with new, allocator calls, string concatenation, inline assembly and the syscall built-in as their sources. A call outside the program with no with clause may allocate; a call through a function type with no with clause may perform anything, and a forbidding function that reaches one is refused for that reason.

Fix: remove the effect from the path, declare the extern with none or with what it does, or give the function type a with clause.
