L0001A metafunction could not run

Reported by the compiler as an error or warning.

mettle explain L0001

A decorator names no @layout or @generate function, or the one it names trapped, ran out of steps, or returned something the compiler could not read. Metafunctions run in the compile-time interpreter before the program is type checked.

Fix: import the module that declares the decorator, or fix the function the diagnostic names. --meta-budget=N sets its step budget.
