M0125A signed value compared with an unsigned one

Reported by the compiler as an error or warning.

mettle explain M0125

A comparison of a signed and an unsigned integer happens in the wider of the two types. When the signed side is the wider, every value of both fits and the answer is exact. When the unsigned side is as wide or wider, the comparison is unsigned, so a negative value reads as a huge one.

Example

var i: int32 = -1;
if (i < s.length) { ... }     // M0125: false, s.length is uint64

The warning stays quiet when the signed side cannot be negative: a constant, a for range counter, or a value a dominating test bounds.

Fix: cast one side so the comparison says what it means.

if ((int64)i < (int64)s.length) { ... }
