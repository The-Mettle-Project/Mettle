tensor-scalar-replayA tensor_matmul runs one element at a time

Reported by --explain after a verdict.

mettle explain tensor-scalar-replay

No tensor instruction on this target fits the operation, or the one that fits needs more registers than the budget allows. The whole warp then computes the product element by element in the order the numerics contract fixes, so the result is the same and the speed is that of scalar code.

Fix: where the reason is the budget, raise it with --gpu-tensor-tuple-budget=N. Otherwise pick element types and a shape the target has an instruction for.
