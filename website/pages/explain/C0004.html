C0004A kernel walks K in an order its contract does not allow

Reported by the compiler as an error or warning.

mettle explain C0004

A contract with k_order: k_ascending promises that every tensor accumulation visits K in ascending order, one chain from the first block to the last. The check reads the order off each output's chain: which input bytes each MMA step's B operand came from. A member that reorders the blocks, or splits K into partial sums added afterwards, rounds differently from one that walks K once in order.

Fix: accumulate the blocks in ascending order into one accumulator.
