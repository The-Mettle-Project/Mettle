F0002A function requires an effect nothing provides

Reported by the compiler as an error or warning.

mettle explain F0002

A function declared requires E may only run where E is provided, and the compiler found a way to reach it from a place that provides nothing: main, an interrupt handler, a naked function, a kernel, a test, or an exported function of a shared library.

A requirement travels up the call graph until a caller declares provides E, which grants the effect to everything its body calls. This is how thread affinity, a held lock, or an initialised subsystem becomes something the compiler checks: the function that owns the thread provides the effect, and every function that needs it says so.

Fix: call the function from inside something that provides E, or make the entry point provide it because it really does.
