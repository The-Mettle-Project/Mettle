register-tilesThe registers a kernel's tiles hold

Reported by --explain after a verdict.

mettle explain register-tiles

A local whose type is a fragment layout is a register tile: one work item's share of an MMA tile, held in registers. The report lists each tile with the registers it takes and the lines it is live across, and the peak for the kernel against the budget of 255 a work item. An intermediate tile used once is computed one element at a time and holds none.
