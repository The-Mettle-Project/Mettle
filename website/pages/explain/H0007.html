H0007A phase joins the threads and there is nothing to build it out of

Reported by the compiler as an error or warning.

mettle explain H0007

joins: true on a phase says every thread waits at that phase's boundary before any of them starts the next frame. The wait is generated out of std/thread's atomics, so the module has to import them.

Fix: import "std/thread"; beside the schedule.

The counter behind a join only ever rises: a thread arriving for frame g leaves it at g times the number of threads, so there is nothing to reset and nothing to race over. It is volatile, so the spin reads memory every time round.
