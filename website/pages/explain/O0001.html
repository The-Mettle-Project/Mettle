O0001Use of a value after it moved

Reported by the compiler as an error or warning.

mettle explain O0001

A value that owns a resource moved: into a by-value parameter, a return, a variable, a field or a drop. After a move the old name no longer holds anything, so reading it, borrowing it or moving it again is an error. "On some paths" means one branch moved it and another did not.

var a = open("log");
consume(a);
write(&a, "x");    // a moved into consume

Fix: pass a pointer (&a) to a function that only needs to look, or put a new value in a before using it again.
