scatter-storeA store whose index the loop reads from memory

Reported by --explain after a verdict.

mettle explain scatter-store

When the element a store writes is chosen by data, heat[cell] = ... with cell read from an array, the store is a scatter. AVX2 can gather loads but has no scatter store, so a vector body would still store one lane at a time.

The commonest case is a histogram, h[x[i]] = h[x[i]] + 1. Two lanes of one vector can pick the same element, and a vector update would keep only one of the two increments. AVX-512 detects that collision with vpconflictd; AVX2 cannot, and the scalar loop is the floor.
