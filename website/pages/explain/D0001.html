D0001A function's longest path costs more than its deadline

Reported by the compiler as an error or warning.

mettle explain D0001

where cycles < N on a function is a claim about its longest path, and the compiler costs that path from a model of the target: one cost per instruction, a call costed at what the callee's own longest path costs, and a loop costed at its body times a trip count taken from the loop's own bound.

Example

fn tick(seed: int32) -> int32 where cycles < 60 {   // D0001
  var i: int32 = 0;
  while (i < 8) { seed = mix(seed); i = i + 1; }
  return seed;
}

--report-deadlines prints the path block by block with what each one costs, which is where the work actually is.

The model costs the IR as lowered, before the optimizer runs, so the number is an upper bound on the work the program asked for rather than a prediction of a particular machine's cycles.

Fixes

  • raise the deadline to what the path costs

  • take work off the longest path, which the report names
