L0007A pass the program wrote produced code the compiler refused

Reported by the compiler as an error or warning.

mettle explain L0007

A @pass function runs on the optimizer's IR for a function and writes code back. The compiler checks that code before it replaces the original, and refused it. The message says which check failed: the pass wrote text that does not print, named an operation the IR does not have, broke the shape of the function, or changed what the function does, in which case the counterexample follows.

The original function is kept and the build stops.

Fix: run the pass on the smaller function the counterexample names and compare the IR it writes with the IR it read.
