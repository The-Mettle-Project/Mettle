P0002A bounds check was proven away by a declared type

Reported by the compiler as an error or warning.

mettle explain P0002

Not an error. --explain reports it: an index whose declared type pins its range inside the array it indexes needs no bounds check, so none was emitted, in debug, release and --safe builds alike. The proof is the type's predicate; the pass that consumed it is lowering, which decides check emission per access.

A property the program declared and the compiler proved earns the same treatment as one the compiler discovered on its own, and no more: an index of a plain integer type keeps its check.

The prover is code, so it is not believed on its own authority. mettle test, mettle trace and --verify re-check every proven conversion as the interpreter runs, and --check-proofs does the same inside a compiled program, in --release too.
