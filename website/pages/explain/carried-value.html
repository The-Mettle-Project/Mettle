carried-valueA value carried from one iteration into the next

Reported by --explain after a verdict.

mettle explain carried-value

Lanes run eight iterations side by side, so no iteration may read what the one before it wrote, except through a running sum, which regroups. The remark names the value and how it is carried:

  • Through an operation other than + or -, as in a hash or a filter. That chain is the algorithm, and the loop is at its scalar floor.

  • As the previous element, prev = x[i] read on the next pass. Read x[i - 1] from the array instead.

  • As the value from the last iteration whose condition held. Find that index in a loop of its own.

  • As a sum wider than 32 bits. Accumulate in int32 or float32 and widen after the loop.
