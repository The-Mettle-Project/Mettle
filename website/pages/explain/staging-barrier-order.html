staging-barrier-orderCopies into workgroup memory were not staged asynchronously

Reported by --explain after a verdict.

mettle explain staging-barrier-order

A run of copies from global to workgroup memory followed by a workgroup barrier is the shape asynchronous staging takes: the copies are issued, and the barrier waits for them. That is only valid when the barrier publishes what was copied, which takes one that both acquires and releases. This one does less, so the copies stay ordinary loads and stores.

Fix: write barrier(workgroup, acq_rel).
