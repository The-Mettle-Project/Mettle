P0001A declared type's rule could not be proven here

Reported by the compiler as an error or warning.

mettle explain P0001

A value flows into a type declared with type Name = Base where predicate;, and the compiler could not prove the predicate for it. The message names the conjunct it could not establish, the expression, and the range it knew for it.

The proof is the compiler's job and never an annotation. It proves a conversion from a constant, from the value's own type (a uint8 is 0..255, a Digit is 0..9), from arithmetic it can bound (x & 63, n % 10, a + b over known ranges), from a loop bound, from a dominating if whose condition implies the predicate, from an early exit that rules the other case out, and from a guard that repeats the predicate itself (if (is_valid(s)) for where is_valid(value)). Past that it refuses to guess, which is this error.

A declared type with no predicate (type Meters = float64;) is a unit: a plain base value becomes one only by a cast, and two such types never mix in arithmetic.

Fix: guard the value where it is converted, or narrow what it is computed from.

The predicate speaks about value unless the declaration names the binding itself: type Slot = uint32 where n: n < 64;.
