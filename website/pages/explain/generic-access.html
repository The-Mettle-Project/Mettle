generic-accessA load or store goes through the generic address space

Reported by --explain after a verdict.

mettle explain generic-access

A device pointer whose type names its space loads with ld.global, ld.shared or ld.local. A plain T* that can hold a workgroup or a private address is a generic pointer: the address is converted where it becomes one, and every access through it resolves the space at run time. A kernel's own plain pointer parameters only ever hold global addresses, so they still load .global; this remark is about helpers called with more than one kind of address.

Metal has no generic space. The same helper is compiled once for each space it is called with, and the report says how many copies it made.

Fix: name the space in the helper's parameter type, T global*, T shared* or T local*.
