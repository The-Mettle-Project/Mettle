C0002The numerics check cannot follow a computation

Reported by the compiler as an error or warning.

mettle explain C0002

The check follows integer and floating-point arithmetic, conversions, loads and stores, copies, subgroup operations, tensor MMAs and the math intrinsics on values computed from the contract's inputs. It stops, and the build fails, where it cannot decide what happens: a branch, address or loop bound computed from the inputs (a branch whose arms only compute values is followed as a select), an operation with no meaning here such as inline asm or an extern call, a read of bytes an asynchronous copy has not delivered, or an interpreter limit. The message names the line.

Fix: compute the decision from indices and sizes, which the check knows, or write the data-dependent choice as an assignment in both arms.
