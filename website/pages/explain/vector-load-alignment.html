vector-load-alignmentAdjacent loads stayed separate for want of a declared alignment

Reported by --explain after a verdict.

mettle explain vector-load-alignment

The kernel loads two or four adjacent elements from one pointer, which is the shape of a vector load. A vector load of N elements needs the address aligned to N elements, and the pointer's type declares less than that or nothing, so each element is loaded on its own.

Fix: declare the alignment in the pointer's type, such as float32 global align(16)*. On a kernel parameter the launch is then held to it. On a computed address the cast to the aligned type is accepted where the compiler can prove the offset is a multiple of the alignment, which a declared type on the offset gives it.
