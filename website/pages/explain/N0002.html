N0002A described machine has no program to run

Reported by the compiler as an error or warning.

mettle explain N0002

mettle emulate assembles const PROGRAM: string[N], one assembly line per row, into the machine's own encoding. A file describing a machine and nothing to run on it has only half of what is needed.

Example

const PROGRAM: string[2] = [ "seti 0, 5", "out 0" ];
